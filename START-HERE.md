# Start here

## Use it now on this computer

1. Double-click **run-local.cmd**.
2. Your browser opens the ICT600 Revision Hub.
3. Keep the small terminal window open while using the hub.
4. Close the terminal window when finished.

## Use it after GitHub publishing

Open <https://ilmu-repo.github.io/ict600-revision-hub/> on any phone or computer. On a phone, use the browser menu and choose **Add to Home Screen** or **Install app**. After the first successful visit, the core activities remain available offline.

## Suggested end-of-lecture routine

1. Choose **Lecture wrap-up**.
2. Select the chapter just completed.
3. Give students 8–12 minutes to answer all six activities.
4. Ask students to commit to subjective or coding answers before revealing the model.
5. Discuss common review items, then let students retry them.

## Marking principle

Objective items are automatically marked. Explanations and code are not judged by brittle exact-word matching. Students compare their attempt with a model answer and checklist, then choose **Got it**, **Almost**, or **Review**. Equivalent correct wording and alternative valid coding solutions are accepted.
